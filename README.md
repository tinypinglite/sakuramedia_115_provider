# SakuraMedia 115 网盘 Provider

把 115 网盘接入 SakuraMedia 的媒体库，提供文件浏览、影片导入、115 离线下载、播放、缩略图和片段。

## 安装

在 SakuraMedia 的「系统设置 → 插件」点击「安装插件」，上传本插件的 `.zip` 包；安装后确认插件已启用，再重启 SakuraMedia 容器。插件的安装、启停、删除或插件配置修改后，前端都会提示需要重启容器才生效。

## 创建媒体库

在「系统设置 → 媒体库」点击「新增媒体库」，将「存储 Provider」设为「115 网盘」，再填写：

- 名称：媒体库在 SakuraMedia 中的显示名称。
- 115 Web Cookie：从 115 网页端复制的 Cookie。填写后保存时会按「115 登录设备」换取独立设备登录；与「115 专用设备 Cookie」至少填写一个。
- 115 登录设备：可选 `wechatmini`（微信小程序）或 `alipaymini`（支付宝小程序），留空默认 `alipaymini`。仅控制自动换取渠道；直接粘贴设备 Cookie 时不受此项影响。
- 115 专用设备 Cookie：留空时由 Web Cookie 自动换取并保存在配置里；也可以直接粘贴微信/支付宝小程序的设备 Cookie，保存时会校验登录是否有效。
- 115 媒体目录：导入影片的目标目录，填写 115 绝对路径，例如 `/sakuramedia-media`。
- 115 离线下载目录：115 离线任务的保存目录，填写 115 绝对路径，例如 `/sakuramedia-downloads`。

保存时会校验可用的登录凭据与两个目录。Cookie 字段是普通文本，编辑媒体库时会明文显示当前值，可直接修改；存储 Provider 不能在编辑页改为其他类型，需要新建媒体库后再迁移。

不要把 Cookie 提交到 issue、日志或截图中。插件按「115 登录设备」登录 115；请不要再用同一账号在同一渠道手动登录，以免影响插件会话。Cookie 失效后，在编辑媒体库时重新填写并保存即可。

## 插件设置

在「系统设置 → 插件」进入「115 网盘」的设置，可以调整：

- 缩略图 HLS 分片并发数：同时下载并解码的 HLS 分片数量，默认 `1`，范围 `1-16`。调大可加快缩略图生成（单部影片的分片耗时近似随并发数线性下降），过高可能触发网盘限速；修改后需重启容器生效。

## 115 离线下载

在「系统设置 → 下载器」点击「新建下载器」，选择上一步创建的 115 媒体库作为「目标媒体库」。115 离线下载没有额外的下载器配置字段；可点击「测试配置」检查设备登录，再保存下载器。

离线任务会写入配置的「115 离线下载目录」，完成后可作为影片导入源。删除 SakuraMedia 中的下载器不会删除已经提交到 115 的离线任务。

离线任务在「115 离线下载目录」下按「番号-哈希前 6 位」建立专属子目录（旧任务保留原目录名）。在「下载任务」中删除任务时：不勾选「同时删除下载器中的文件」只移除 115 离线任务；勾选后会同时删除任务文件和专属目录，目录清理失败仅记录日志，不影响任务删除。

## 导入与播放

浏览时可从 115 账号中的目录选择导入源；影片导入后位于配置的「115 媒体目录」。保留源文件时在 115 内复制，选择导入后删除源文件时则在提交成功后移动。

115 默认使用 302 直连：优先播放已就绪的 HLS，明确未就绪时播放原文件。显式请求后端代理时同样优先 HLS；鉴权、风控和网络错误不会被当作转码未就绪。

HLS 直连解析不进入账号级请求间隔队列。插件在进程内缓存选中的 HLS 地址 10 分钟、明确无 HLS 的结果 5 秒，同一媒体的并发解析共用一次上游请求链；其他错误不缓存。原文件直链沿用独立缓存。缓存不会落盘，过期后由下一次播放请求重新解析。

## 手动清理

插件注册了一个仅手动执行的任务，执行请求必须明确提供 `{"confirm": true}`：

- `sakuramedia_115_cleanup_empty_media_dirs`：递归扫描配置的媒体目录，只删除没有文件且没有非空子目录的子目录，删除前再次递归检查候选子树是否有文件，配置的媒体根目录本身不会删除。

任务使用 115 目录分页和批量删除接口，不逐个文件发请求。
