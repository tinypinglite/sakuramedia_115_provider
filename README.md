# SakuraMedia 115 网盘 Provider

把 115 网盘接入 SakuraMedia 的媒体库，提供文件浏览、影片导入、115 离线下载、播放、缩略图和片段。

## 安装

在 SakuraMedia 的「系统设置 → 插件」点击「安装插件」，上传本插件的 `.zip` 包；安装后确认插件已启用，再重启 SakuraMedia 容器。插件的安装、启停、删除或插件配置修改后，前端都会提示需要重启容器才生效。

## 创建媒体库

在「系统设置 → 媒体库」点击「新增媒体库」，将「存储 Provider」设为「115 网盘」，再填写：

- 名称：媒体库在 SakuraMedia 中的显示名称。
- 115 Web Cookie：从 115 网页端复制的 Cookie。保存时会校验登录，并换取供后台任务和播放使用的支付宝小程序专用登录。
- 115 媒体目录：导入影片的目标目录，填写 115 绝对路径，例如 `/sakuramedia-media`。
- 115 离线下载目录：115 离线任务的保存目录，填写 115 绝对路径，例如 `/sakuramedia-downloads`。

保存时会校验 Cookie 与两个目录。编辑已有媒体库时，Web Cookie 留空表示保留原值；存储 Provider 不能在编辑页改为其他类型，需要新建媒体库后再迁移。

不要把 Cookie 提交到 issue、日志或截图中。插件会使用支付宝小程序渠道登录 115；请不要再用同一账号在该渠道手动登录，以免影响插件会话。Cookie 失效后，在编辑媒体库时重新填写并保存即可。

## 115 离线下载

在「系统设置 → 下载器」点击「新建下载器」，选择上一步创建的 115 媒体库作为「目标媒体库」。115 离线下载没有额外的下载器配置字段；可点击「测试配置」检查设备登录，再保存下载器。

离线任务会写入配置的「115 离线下载目录」，完成后可作为影片导入源。删除 SakuraMedia 中的下载器不会删除已经提交到 115 的离线任务。

## 导入与播放

浏览时可从 115 账号中的目录选择导入源；影片导入后位于配置的「115 媒体目录」。保留源文件时在 115 内复制，选择导入后删除源文件时则在提交成功后移动。

115 默认使用 302 直连：优先播放已就绪的 HLS，明确未就绪时播放原文件。显式请求后端代理时同样优先 HLS；鉴权、风控和网络错误不会被当作转码未就绪。

HLS 直连解析不进入账号级请求间隔队列。插件在进程内缓存选中的 HLS 地址 10 分钟、明确无 HLS 的结果 5 秒，同一媒体的并发解析共用一次上游请求链；其他错误不缓存。原文件直链沿用独立缓存。缓存不会落盘，过期后由下一次播放请求重新解析。
